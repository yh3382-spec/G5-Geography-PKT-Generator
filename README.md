# Grade 5 Geography Map Skills Review

An A4 printable review packet for map legends, compass directions, scale, latitude, longitude, the equator, and the prime meridian. It includes 20 multiple-choice and short-answer questions, two published maps, and a teacher answer key.

## Download

[Printable review packet](packet/grade5_geography_map_skills_review.pdf)

Print at **A4, actual size**. Student pages are 1–5; page 6 is the teacher answer key.

## Rebuild the PDF

Install ReportLab, then run:

```sh
python scripts/build_packet.py
```

The script reads the images in `assets/` and writes the PDF in `packet/`.

## Map sources

- Hampton National Historic Site park map: [U.S. National Park Service classroom worksheet, page 2](https://www.nps.gov/common/uploads/teachers/lessonplans/HAMP%20scavenger.pdf). The map image in `assets/` is cropped from that page for A4 readability.
- Latitude and longitude globe: [NOAA Science On a Sphere, Latitude Longitude Layers](https://sos.noaa.gov/catalog/datasets/latitude-longitude-layers/). The map image in `assets/` is NOAA's published image.

The packet links to both original sources. Its questions and answer key are written for the included map images.
